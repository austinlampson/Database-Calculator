# Lampson Database Calculator

Realtor-facing database opportunity calculator for The Lampson Team at CrossCountry Mortgage.

## Files
- `index.html` — the whole site (calculator, styles, script)
- `logo.png` — add your logo here (5476 x 748 px). Until it exists, a dashed placeholder shows.
- `netlify.toml` — tells Netlify there is no build step; publish this folder as-is.

## Leads
The "Send my results to Austin" form posts to Netlify Forms (form name: `database-lead`).
See submissions in Netlify: Site > Forms. Set email notifications under Site configuration > Notifications > Emails and webhooks > Form submission notifications.
